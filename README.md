## Previous wordpress version of https://justingosses.com

From 2015-2022, my personal website was a WordPress site at justingosses.com. 

This repository has several branches that holds versions of the old
WordPress website that have been exported into working HTML, CSS,
and JavaScript files. 

These exports were made at two time periods (2019 & 2022) created with the WordPress Plugin "Simply-Static".

They exist in [master](https://github.com/JustinGOSSES/JustinGOSSES.github.io),
[frozen_2019](https://github.com/JustinGOSSES/JustinGOSSES.github.io/tree/frozen_2019),
and [frozen_2022](https://github.com/JustinGOSSES/JustinGOSSES.github.io/tree/frozen_2022)
branches. 

The latest of those two snapshots is visible as a github pages page at https://justingosses.github.io/ .
